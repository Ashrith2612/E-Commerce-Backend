# E-commerce Backend Application

## Overview
This project is a backend application for an E-commerce system developed using Java and Spring Boot. It provides RESTful APIs to manage product information and perform database operations. The application follows a layered architecture to separate business logic, data access, and request handling.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- REST APIs
- Maven
- Postman

## Features
- Product management through REST APIs.
- Create, retrieve, update, and delete product records.
- Database integration using Spring Data JPA and Hibernate.
- Entity mapping and database persistence.
- Request and response handling.
- Exception handling for application errors.

## Project Structure
- **Controller Layer:** Handles incoming HTTP requests and API endpoints.
- **Service Layer:** Contains business logic and application operations.
- **Repository Layer:** Handles database interactions using Spring Data JPA.
- **Entity Layer:** Defines application entities and database mappings.

## API Operations
The application supports CRUD operations for managing product information through REST endpoints.

## Learning Outcomes
- Gained practical experience in developing REST APIs using Spring Boot.
- Understood layered architecture in backend development.
- Learned database integration using JPA and Hibernate.
- Practised implementing CRUD operations and managing persistent data.

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Configure PostgreSQL database credentials in `application.properties`.
4. Build the project using Maven.
5. Run the Spring Boot application.
6. Test the REST APIs using Postman.
